Vehicle Controller

Supervisory control for electrical and electrothermal vehicles

Component path: Components / Controller

Open Default ModelOpen Vehicle Model

Description

Vehicle controller for the BEV system model. Manages torque distribution, regenerative braking, and drive-mode selection. Multiple controller variants are available for different simulation fidelities. For the battery management system, see the BMS component.

How to choose a fidelity

Use Controller for the maintained full torque, AWD, and regenerative-braking logic; ControllerFRM for large sweeps where controller execution cost dominates; and ControllerHVAC when cabin commands must be coordinated with propulsion control.

Fidelity at a glance

ModelDescriptionUse caseTemplatesDocumentation & files

Where it participates

  • Range Estimation (Workflow/Vehicle/RangeEstimation/) — Controller manages torque split and regenerative braking during drive-cycle runs.
  • All Vehicle Templates — Every shipped vehicle configuration references a Controller variant for supervisory control.
