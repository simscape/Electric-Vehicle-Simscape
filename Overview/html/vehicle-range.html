Vehicle Models, Templates, and Presets

Choose a physical scope, apply a maintained preset, then parameterize the assembled BEV model

Open BEV Setup AppOpen Preset PickerOpen BEV System Model

The top-level BEVsystemModel.slx composes one vehicle template with shared component models. Templates establish the physical domains; presets select maintained model references and parameters; the app lets the user adjust those choices without navigating the repository tree.

Apply a Shipped Preset

Presets are replayable setup folders under Script_Data/Setup/Preset. Each contains model-reference selection, parameter setup, and one applyPreset.m entry point.

  1. Open the preset pickerOpen Preset Picker

    Preview the available vehicle configurations.

  2. Choose a default preset

    Select the electrical, auxiliary, or electrothermal starting point shown above.

  3. Inspect the assembled modelOpen BEV System Model

    Open BEVsystemModel.slx and verify the active template and component references.

What the App Applies or Produces

Saved setup JSON

Captures template, component, environment, HVAC, driver, and control selections for later reuse.

Model-reference setup

Generates a replayable script that selects the template and shared component Subsystem References.

Parameter setup

Generates a MATLAB script that calls linked component parameter files.

Build snapshot

Writes a README describing the configured model so the result can be reviewed and reproduced.
