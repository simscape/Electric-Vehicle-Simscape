Select Gear Ratio for Electric Vehicle

Open Motor drive thermal test benchOpen Live Script

A fixed gear ratio is usually the most cost-effective drive-unit choice for a BEV, but the ratio must let the motor meet the duty cycle without overheating.

This workflow runs a design of experiment across candidate gear ratios and test cycles (EUDC and US06) on the motor thermal test bench, recording pass/fail against the same winding and magnet temperature limits used in the durability test. The magnet and winding temperature plots reveal the minimum ratio that survives the demanding cycle.

Quick Setup

  1. Open the workflow Live ScriptOpen Live Script

    Open minimumRequiredGearRatio.mlx to compare candidate gear ratios over the EUDC and US06 cycles.

  2. Use precomputed results or run the sweepOpen batch runner

    Review BatchRunTemp.mat, or run testThermalBenchRun with the required ratios, cycles, and durations.

  3. Sweep ratios across the duty cyclesOpen thermal test bench

    Record winding and magnet temperatures for every ratio and cycle, together with the resulting Pass or Fail status.

  4. Plot and choose the ratioOpen result plotting

    Compare the temperature histories and confirm that the selected ratio satisfies the thermal, speed, and torque limits.

Expected Results

The workflow produces these result types:

  • Winding and magnet temperature histories grouped by gear ratio
  • EUDC and US06 thermal comparisons
  • Minimum acceptable or preferred ratio for the selected duty cycle

Checks Before Using Results

  • Verify the same thermal initial state is used for every ratio.
  • Check both winding and magnet limits.
  • Confirm the candidate ratio also meets speed and torque constraints.
